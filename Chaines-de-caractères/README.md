## Exercices sur les chaîne de caractères

Il y a un fichier par exercice

Dans le dossier "Variables", lancez : 

```node exoX.js.``` (X est le numéro du fichier.)

# Chaines-de-caractères — Exercice 1

Énoncé :
Écris un programme qui :

Déclare une variable prenom et une variable nom.

Affiche dans la console : "Bonjour, <prenom> <nom> !".

# Chaines-de-caractères — Exercice 2

Énoncé :
Écris un programme qui :

Déclare une variable phrase contenant une phrase.

Affiche le nombre de caractères dans cette phrase.

# Chaines-de-caractères — Exercice 3

Énoncé :
Écris un programme qui :

Déclare une variable texte contenant une phrase.

Affiche la première lettre et la dernière lettre de la phrase.

# Chaines-de-caractères — Exercice 4

Énoncé :
Écris un programme qui :

Déclare une variable texte contenant une phrase.

Transforme la phrase en majuscules puis affiche le résultat.

# Chaines-de-caractères — Exercice 5

Énoncé :
Écris un programme qui :

Déclare une variable texte contenant une phrase.

Remplace tous les espaces par des tirets - et affiche le résultat.

# Exercice 6 — Vérifier la présence d’un mot dans une phrase

👉 Énoncé :
Écris un programme qui vérifie si le mot "chat" est présent dans la phrase suivante :

const phrase = "Le petit chat est sur le toit.";

S’il est présent, affiche "Le mot 'chat' est présent", sinon affiche "Le mot 'chat' est absent".
