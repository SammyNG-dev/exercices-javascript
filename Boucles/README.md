## Exercices sur les boucles

Il y a un fichier par exercice

Dans le dossier "Variables", lancez : 

```node exoX.js.``` (X est le numéro du fichier.)

# Boucles — Exercice 1

Énoncé :
Écris un programme qui affiche tous les nombres de 1 à 10 dans la console.

# Boucles — Exercice 2

Énoncé :
Écris un programme qui affiche tous les nombres pairs entre 1 et 20.

# Boucles — Exercice 3

Énoncé :
Écris un programme qui affiche la table de multiplication de 5 (de 1×5 à 10×5).
